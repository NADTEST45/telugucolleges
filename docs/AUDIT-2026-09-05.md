# Code and content audit — 5 September 2026

This audit prioritised admissions freshness, the cutoff landing pages, dependency security, and anonymous submission handling. It reviewed the existing predictor/data validation suite and exercised the updated site locally. It does **not** certify that every college's fee, accreditation, scholarship or placement figure has been reverified for September.

## Source review

- [TGCHE 2026 detailed notification](https://tgeapcetd.nic.in/files/TGEAPCET2026DETNOTIFICATION.PDF), dated 8 June 2026, reviewed 5 September: pages 1–3 give the three phases, final reporting through 7 August, and internal-sliding reporting through 17 August. These are **published schedule dates**, not independently confirmed completion events.
- [TGCHE admissions portal](https://tgeapcet.nic.in/): search-index content lists spot-admission resources and 2025 last-rank statements. Direct retrieval was intermittent. A retrieved [candidate spot-admission PDF](https://tgeapcetd.nic.in/files/CandidateSpotAdmissions.pdf) carries **2025** dates, so it was not used to announce a 2026 spot deadline.
- [AP EAPCET results form](https://cets.apsche.ap.gov.in/eapcet/Eapcet/EAPCET_GetResult.aspx): available during review; asks for registration number and EAPCET hall ticket number. Result availability was confirmed; this review did not independently re-establish the existing declaration date, pass statistics or topper list.
- [AP counselling portal](https://eapcet-sche.aptonline.in/EAPCET/): timed out through both web retrieval and browser navigation. No current AP counselling deadline was substituted from assumptions or a previous year's schedule.
- [NIRF 2025 engineering rankings](https://www.nirfindia.org/Rankings/2025/EngineeringRanking.html): official 2025 results were discoverable. No verified 2026 rankings were imported or inferred.
- Dependency evidence: npm registry audit on 5 September 2026. Resolved versions include Next.js 16.3.4, PostCSS 8.5.28, sharp 0.35.4, DOMPurify 3.4.14, fflate 0.8.3, js-yaml 4.3.2 and nanoid 3.3.18. Lockfile records the full transitive changes.

## Verification

- `npm run ci`: type checking, linting, and **38 tests across 11 files passed**.
- Nine new tests cover India-time expiry, old/future news, status fallback, calendar dates/portal, 2025 cutoff inclusion/sorting, malformed JSON, byte limits and streamed cancellation.
- Local HTTP checks: both public submission routes returned 400 for null/malformed JSON, 415 for text/plain and 413 for oversized payloads. No valid lead/report was submitted.
- Predictor smoke check: Telangana CSE, OC boys, rank 10,000 returned HTTP 200 and 134 results.
- Browser checks: news state filtering works; July notices display archive labels; counselling tables display elapsed dates; the CSE cutoff table displays the 2025 column (142 colleges). At a 390-pixel viewport the news page had no horizontal overflow.
- Local preview displayed a development-only React eval/debugging warning under the existing CSP. Production CSP was not weakened to suppress it.
- A full production build and deployment were **not run**, following the repository's build/push constraint in CLAUDE.md. Vercel must build and validate the production output after push.

## Remaining editorial work

1. Recheck the AP counselling portal when reachable, record the exact active-round notification and expiry, and replace the explicitly unconfirmed status.
2. Import any verified 2026 last-rank statements using the canonical branch taxonomy and source category/gender conventions. AP's stored data currently extends through 2024; TG's through 2025. Missing statements must not be approximated and advertised as official.
3. Reverify university-specific 2026-27 fees, scholarship terms, accreditation validity and placement reporting years individually. The existing overall college-data verification date was deliberately not advanced by this narrower audit.
4. Revisit historical articles whose publication dates and later edits are mixed; archive labels now prevent live promotion, but archival wording may still need editorial correction.

To maintain freshness, update shared status records and their review date together, provide explicit `verifiedAt` and `expiresAt` on new deadline-sensitive news, and cite the actual year's notification. Time-based UI expiry prevents stale promotion; it does not fetch new admissions announcements automatically.
